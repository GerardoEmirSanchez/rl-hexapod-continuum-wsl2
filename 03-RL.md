## Experimento 01: Mapeo Biunívoco 2D $\leftrightarrow$ 1D y la Maldición de la Dimensionalidad

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> 
> 
> El estado planar del hexápodo se modela como una coordenada cartesiana discreta $(r, c)$ en una rejilla de $M$ filas y $N$ columnas. Para que los algoritmos de aprendizaje indexen la memoria sin tensores multidimensionales, se utiliza la función biyectiva de aplanamiento *Row-Major*:
> $$s = \Phi(r, c) = r \cdot N + c, \qquad r = \lfloor s / N \rfloor, \quad c = s \pmod N$$
> 
> 
> El número de columnas $N$ define el ancho de paso entre filas: si el entorno se ensancha de $N = 5$ a $N = 10$, la misma posición física $(r, c)$ recibe un índice de estado $s$ distinto, duplicando el tamaño de la matriz $Q(s, a)$ en memoria RAM.
> Si el sistema escala de la rejilla planar a $D$ dimensiones continuas del robot (posición tridimensional, orientación y curvatura de los tendones del continuum flexible de TPU) cuantizadas en $k$ divisiones por eje, el espacio total explota exponencialmente como:
> $$\vert{}\mathcal{S}\vert{} = k^D$$
> 
> 
> El requerimiento de memoria RAM en Megabytes para almacenar la tabla $Q(s, a)$ en doble precisión (8 bytes por número) bajo $\vert{}\mathcal{A}\vert{}$ acciones motrices es:
> $$\text{Memoria (MB)} = \frac{k^D \times \vert{}\mathcal{A}\vert{} \times 8}{1024^2}$$
> 
>

## Experimento 02: Simulación Monte Carlo 2D: El Fracaso del Agente Ciego

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> 
> 
> Bajo una política aleatoria uniforme $\pi(a \mid s) = \frac{1}{\vert{}\mathcal{A}\vert{}} = 0.25$, el movimiento del robot corresponde a una caminata aleatoria bidimensional confinada con barreras reflectantes (las paredes perimetrales de la celda de trabajo). La probabilidad combinatoria de alcanzar la meta de forma puramente fortuita decrece drásticamente al incrementar la distancia Manhattan:
> $$d_{\text{Manhattan}}(s_0, s_{\text{meta}}) = \vert{}r_{\text{meta}} - r_0\vert{} + \vert{}c_{\text{meta}} - c_0\vert{}$$
> 
> 
> Al no existir memoria ni gradiente de recompensa que guíe al controlador, el retorno acumulado $G_0 = \sum_{t=0}^{T} \gamma^t R_{t+1}$ colapsa a valores negativos por el agotamiento del tiempo límite ($T_{\max} = 35\text{ pasos}$) o por impacto directo contra las esquinas metálicas del banco de trabajo.

```python
# ============================================================================
# EXPERIMENTO 02: MONTE CARLO DEL AGENTE CIEGO EN ENTORNO 2D (500 EPISODIOS)
# ============================================================================
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import random

# Fijar semillas estocásticas para reproducibilidad experimental
random.seed(42)
np.random.seed(42)

# ----------------------------------------------------------------------------
# 1. PARÁMETRO EXPERIMENTAL 
# ----------------------------------------------------------------------------
pos_inicio = (2, 0)  

# ----------------------------------------------------------------------------
# 2. MOTOR DE SIMULACIÓN MONTE CARLO (500 EPISODIOS)
# ----------------------------------------------------------------------------
class SimuladorPlano2D:
    def __init__(self, filas=5, columnas=5):
        self.filas = filas
        self.columnas = columnas
        self.meta = (2, 4)                  # Boca de la gaveta (+100 pts)
        self.obstaculos = [(0, 4), (4, 4)]  # Esquinas metálicas / Choque (-50 pts)
        self.acciones = [(-1, 0), (1, 0), (0, -1), (0, 1)] # Arriba, Abajo, Izq, Der
        
    def ejecutar_episodio(self, inicio, max_pasos=35):
        r, c = inicio
        retorno = 0.0
        for paso in range(1, max_pasos + 1):
            dr, dc = random.choice(self.acciones)
            r = max(0, min(self.filas - 1, r + dr))
            c = max(0, min(self.columnas - 1, c + dc))
            
            if (r, c) == self.meta:
                return "Éxito", retorno + 100.0, paso
            elif (r, c) in self.obstaculos:
                return "Colisión", retorno - 50.0, paso
            retorno -= 1.0
            
        return "Timeout", retorno, max_pasos

sim2d = SimuladorPlano2D()
episodios_mc = 500

# Cálculo de distancia Manhattan hacia la meta
d_manhattan = abs(sim2d.meta[0] - pos_inicio[0]) + abs(sim2d.meta[1] - pos_inicio[1])

# Ejecución de los 500 episodios para la posición seleccionada
corridas = [sim2d.ejecutar_episodio(inicio=pos_inicio, max_pasos=35) for _ in range(episodios_mc)]
estados_finales = [c[0] for c in corridas]
retornos = [c[1] for c in corridas]

# Cálculo de métricas
pct_exito = (estados_finales.count("Éxito") / episodios_mc) * 100.0
pct_colision = (estados_finales.count("Colisión") / episodios_mc) * 100.0
pct_timeout = (estados_finales.count("Timeout") / episodios_mc) * 100.0
retorno_medio = np.mean(retornos)

# ----------------------------------------------------------------------------
# 3. REPORTE DE RESULTADOS EN CONSOLA (COPIAR DIRECTO A LA TABLA 02)
# ----------------------------------------------------------------------------
print("=" * 70)
print(f" RESULTADOS MONTE CARLO PARA pos_inicio = {pos_inicio}")
print("=" * 70)
print(f" -> Distancia Manhattan (d):    {d_manhattan} casillas")
print(f" -> Porcentaje de Éxitos:       {pct_exito:.1f}% ({estados_finales.count('Éxito')}/{episodios_mc})")
print(f" -> Porcentaje de Colisiones:   {pct_colision:.1f}% ({estados_finales.count('Colisión')}/{episodios_mc})")
print(f" -> Porcentaje de Timeouts:     {pct_timeout:.1f}% ({estados_finales.count('Timeout')}/{episodios_mc})")
print(f" -> Retorno Promedio (G0):      {retorno_medio:.2f} puntos")
print("=" * 70)

# ----------------------------------------------------------------------------
# 4. GRÁFICA DE FRECUENCIAS
# ----------------------------------------------------------------------------
plt.figure(figsize=(6, 3.5), dpi=110)
orden_desenlaces = ["Timeout", "Colisión", "Éxito"]

sns.countplot(
    x=estados_finales, 
    order=orden_desenlaces,
    hue=estados_finales, 
    palette=['#ef4444', '#f59e0b', '#22c55e'], 
    legend=False
)

plt.title(f'Resultados Monte Carlo (500 ep) | Inicio: {pos_inicio} (d={d_manhattan})', fontweight='bold')
plt.xlabel('Desenlace del Episodio')
plt.ylabel('Frecuencia Absoluta')

for i, estado in enumerate(orden_desenlaces):
    conteo = estados_finales.count(estado)
    pct = (conteo / episodios_mc) * 100.0
    plt.text(i, conteo + 5, f"{conteo}\n({pct:.1f}%)", ha='center', va='bottom', fontweight='bold', fontsize=8.5)

plt.ylim(0, max([estados_finales.count(e) for e in orden_desenlaces]) + 50)
plt.grid(True, linestyle='--', alpha=0.3, axis='y')
plt.tight_layout()
plt.show()

```

# Experimento 03: Deriva Anisotrópica y Resbalón en Patas del Hexápodo

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> En condiciones ideales de contacto mecánico, una acción motriz es determinista: $\mathcal{P}(s + \Delta \mathbf{x}_a \mid s, a) = 1.0$. Sin embargo, la presencia de polvo, humedad o desgaste en las suelas de goma de las patas del robot hexápodo introduce una perturbación estocástica lateral (deriva anisotrópica).
> 
> Al enviar la orden nominal de avance frontal hacia la gaveta ($a = \text{DERECHA}$), el modelo de transición se bifurca según la probabilidad de resbalón $p_{\text{resbalon}} \in [0, 1]$:
> 
> $$> \mathcal{P}(s' \mid s, a=\text{DERECHA}) = \begin{cases}  > 1 - p_{\text{resbalon}} & \text{si } s' = (r, c + 1) \quad (\text{Tracción nominal efectiva}) \\  > \dfrac{p_{\text{resbalon}}}{2} & \text{si } s' = (r - 1, c) \quad (\text{Desvío lateral hacia el Norte}) \\  > \dfrac{p_{\text{resbalon}}}{2} & \text{si } s' = (r + 1, c) \quad (\text{Desvío lateral hacia el Sur})  > \end{cases} >$$
> 
> Si la desviación lateral acumulada desplaza al robot hacia las filas extremas ($r = 0$ o $r = 4$), la trayectoria colisiona inevitablemente contra las esquinas metálicas del mueble de herramientas en $(0, 4)$ o $(4, 4)$, penalizando severamente el desempeño mecatrónico.

```python
# ============================================================================
# EXPERIMENTO 03: DERIVA ANISOTRÓPICA Y RESBALÓN ESTOCÁSTICO (30 TRAYECTORIAS)
# ============================================================================
import numpy as np
import matplotlib.pyplot as plt
import random

# Fijar semilla para reproducibilidad
random.seed(42)
np.random.seed(42)

# ----------------------------------------------------------------------------
# 1. PARÁMETRO EXPERIMENTAL (MODIFICAR AQUÍ EN CADA CORRIDA)
# ----------------------------------------------------------------------------
# Probar sucesivamente:
#   Corrida 1: p_resbalon = 0.05 -> Piso seco (tracción alta)
#   Corrida 2: p_resbalon = 0.40 -> Piso húmedo / encerado (deriva moderada)
#   Corrida 3: p_resbalon = 0.85 -> Piso aceitado (pérdida de tracción severa)
p_resbalon = 0.05  # <-- MODIFICA ESTE VALOR PARA CADA FILA DE LA TABLA 03

n_trayectorias = 30
max_pasos = 20

# ----------------------------------------------------------------------------
# 2. MOTOR DE SIMULACIÓN DE TRAYECTORIAS CON DERIVA LATERAL
# ----------------------------------------------------------------------------
pos_inicio = (2, 0)
meta = (2, 4)
obstaculos = [(0, 4), (4, 4)]
acciones = [(-1, 0), (1, 0), (0, -1), (0, 1)]  # 0:Up, 1:Down, 2:Left, 3:Right

trayectorias = []
for _ in range(n_trayectorias):
    pos = pos_inicio
    historial = [pos]
    for _ in range(max_pasos):
        # Política nominal determinista: Avanzar siempre a la derecha (Acción 3)
        acc_nominal = 3
        
        if random.random() < (1.0 - p_resbalon):
            dr, dc = acciones[acc_nominal]  # Tracción frontal efectiva
        else:
            dr, dc = random.choice([(-1, 0), (1, 0)])  # Resbalón ortogonal (Norte/Sur)
            
        r_nuevo = max(0, min(4, pos[0] + dr))
        c_nuevo = max(0, min(4, pos[1] + dc))
        pos = (r_nuevo, c_nuevo)
        historial.append(pos)
        
        if pos == meta or pos in obstaculos:
            break
    trayectorias.append(historial)

# ----------------------------------------------------------------------------
# 3. CÁLCULO DE MÉTRICAS EXPERIMENTALES
# ----------------------------------------------------------------------------
# 1. Desviación lateral promedio respecto al eje central r = 2
desviaciones_medias = [np.mean([abs(r - 2) for r, c in tray]) for tray in trayectorias]
desv_lateral_promedio = np.mean(desviaciones_medias)

# 2. Porcentaje de trayectorias perfectamente rectas (permanecen siempre en r = 2)
trayectorias_rectas = sum(1 for tray in trayectorias if all(r == 2 for r, c in tray))
pct_rectas = (trayectorias_rectas / n_trayectorias) * 100.0

# 3. Porcentaje de trayectorias que terminan en impacto contra obstáculo
choques = sum(1 for tray in trayectorias if tray[-1] in obstaculos)
pct_choques = (choques / n_trayectorias) * 100.0

# ----------------------------------------------------------------------------
# 4. REPORTE DE RESULTADOS EN CONSOLA (COPIAR DIRECTO A LA TABLA 03)
# ----------------------------------------------------------------------------
print("=" * 72)
print(f" RESULTADOS DE PERTURBACIÓN PARA p_resbalon = {p_resbalon} ({n_trayectorias} TRAYECTORIAS)")
print("=" * 72)
print(f" -> Desviación Lateral Media (|ΔY|):     {desv_lateral_promedio:.2f} casillas")
print(f" -> Porcentaje de Trayectorias Rectas:   {pct_rectas:.1f}% ({trayectorias_rectas}/{n_trayectorias})")
print(f" -> Porcentaje de Choques con Obstáculo: {pct_choques:.1f}% ({choques}/{n_trayectorias})")
print("=" * 72)

# ----------------------------------------------------------------------------
# 5. VISUALIZACIÓN GRÁFICA DEL HAZ DE TRAYECTORIAS
# ----------------------------------------------------------------------------
plt.figure(figsize=(6, 5), dpi=110)
plt.xlim(-0.5, 4.5)
plt.ylim(4.5, -0.5)  # Invertir eje Y para que fila 0 quede arriba
plt.xticks(range(5))
plt.yticks(range(5))
```

## Experimento 04: Ingeniería de Recompensas (Reward Shaping vs. Costo Temporal)

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> Si la recompensa es dispersa ($R = 0$ en tránsito y $+100$ al acoplarse), el agente no tiene gradiente de atracción. Para guiar el aprendizaje se aplica *Reward Shaping* basado en el potencial de distancia Manhattan:
>
> $$R_{\text{modificado}} = R_{\text{paso}} + \beta \cdot \left[ d_{\text{Manhattan}}(s_t, \text{meta}) - d_{\text{Manhattan}}(s_{t+1}, \text{meta}) \right]$$
>
> Donde $\beta > 0$ es la ganancia de incentivo de aproximación.

```python
# ============================================================================
# EXPERIMENTO 04: INGENIERÍA DE RECOMPENSAS (SPARSE VS SHAPED REWARD)
# ============================================================================
def calcular_recompensa(pos_actual, pos_siguiente, beta=2.0, meta=(2, 4)):
    d_actual = abs(meta[0] - pos_actual[0]) + abs(meta[1] - pos_actual[1])
    d_sig = abs(meta[0] - pos_siguiente[0]) + abs(meta[1] - pos_siguiente[1])
    
    # Costo base de tiempo
    r_base = -1.0
    # Incentivo de reduccion de distancia
    r_shaping = beta * (d_actual - d_sig)
    
    if pos_siguiente == meta:
        return 100.0
    elif pos_siguiente in [(0, 4), (4, 4)]:
        return -50.0
    return r_base + r_shaping

# Evaluacion: Paso correcto hacia adelante vs retroceso
print(f"Recompensa avanzando hacia meta:   {calcular_recompensa((2,0), (2,1), beta=2.0):.1f} pts")
print(f"Recompensa retrocediendo a pared: {calcular_recompensa((2,1), (2,0), beta=2.0):.1f} pts")
```

> [!TIP]
> ### Protocolo de Laboratorio: Modificación, Ejecución y Observación
> **¿Qué deben modificar?** Alteren $\beta$ entre $0.0$ (penalización pura de batería $-1.0$), $2.0$ (incentivo moderado) y $15.0$ (sobre-incentivo). Evalúen qué sucede si el robot gira en círculos.  
> **¿Qué observarán?** Si $\beta$ es excesivamente alto ($\beta = 15.0$), el robot puede preferir oscilar entre dos celdas intermedias para acumular incentivos locales positivos en lugar de arriesgarse a tocar la gaveta.

| :--- | :---: | :---: | :---: | :--- |
