

## Experimento 05: API Estándar Gymnasium e Inspección de `CliffWalking-v1`

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> 
> 
> En el desarrollo de sistemas ciberfísicos, los algoritmos de control por refuerzo se desacoplan del modelo físico mediante la interfaz universal de **Gymnasium**. Toda invocación al actuador mediante el método `env.step(action)` devuelve de manera estricta la tupla de cinco variables del Proceso de Decisión de Markov:
> $$(s_{t+1}, \; r_{t+1}, \; \text{terminated}, \; \text{truncated}, \; \text{info})$$
> 
> 
> 1. $s_{t+1} \in \mathcal{S}$: Nuevo estado escalar resultante expresado en formato *Row-Major* ($s = r \cdot 12 + c$). La cuadrícula de `CliffWalking-v1` consta de $4 \times 12 = 48\text{ casillas}$ (estados $0$ a $47$).
> 2. $r_{t+1} \in \mathbb{R}$: Señal escalar de refuerzo. Cada paso en superficie transitable cuesta $-1.0\text{ pt}$ (gasto energético de batería), mientras que precipitarse al vacío penaliza con $-100.0\text{ pts}$.
> 
> 
> 3. $\text{terminated} \in \{\text{True}, \text{False}\}$: Bandera booleana que se activa únicamente al alcanzar la meta final ($s = 47$).
> 
> 
> 4. $\text{truncated} \in \{\text{True}, \text{False}\}$: Bandera de seguridad que indica corte por límite de tiempo de cómputo ($T \ge T_{\max}$).
> 
> 
> 5. $\text{info}$: Diccionario con telemetría interna y probabilidades de transición del simulador.
> 
> 
> 
> 
> El espacio de comandos discretos del robot consta de cuatro direcciones:
> $$\mathcal{A} = \{0: \text{Arriba (Up)}, \; 1: \text{Derecha (Right)}, \; 2: \text{Abajo (Down)}, \; 3: \text{Izquierda (Left)}\}$$
> 
>

## Experimento 06: Superficies de Hielo y Estocasticidad en `FrozenLake-v1`

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> 
> 
> En el análisis de sistemas ciberfísicos, la fricción entre el efector final o las ruedas y la superficie de trabajo altera la naturaleza del Proceso de Decisión de Markov (MDP), transformándolo de **determinista** a **estocástico**.
> El entorno estándar `FrozenLake-v1` modela una pista de hielo de $4 \times 4$ celdas ($16$ estados discretos indexados de $0$ a $15$), donde el robot parte de la casilla inicial $S = 0$ y busca acoplarse con la meta $G = 15$ ($R = +1.0$), esquivando los agujeros mortales $H \in \{5, 7, 11, 12\}$ ($R = 0.0$ y fin de episodio).
> Las dinámicas de tracción quedan gobernadas por el parámetro booleano `is_slippery`:
> 1. **Modo Determinista (`is_slippery = False`):** Tracción perfecta sin deslizamiento. La probabilidad de transición es unitaria:
> 
> 
> $$\mathcal{P}(s' \mid s, a) =  > \begin{cases}  > 1.0 & \text{si } s' = s + \Delta \mathbf{x}_a \quad (\text{Dirección comandada}) \\ > 0.0 & \text{en cualquier otra dirección} > \end{cases}$$
> 
> 
> 2. **Modo Estocástico (`is_slippery = True`):** Fricción degradada (hielo puro). El actuador experimenta deslizamiento lateral y solo tiene un tercio de probabilidad de avanzar en la dirección deseada, repartiendo los dos tercios restantes en derivas ortogonales:
> 
> 
> $$\mathcal{P}(s' \mid s, a) =  > \begin{cases}  > 1/3 & \text{si } s' = s + \Delta \mathbf{x}_a \quad (\text{Comando nominal intencionado}) \\ > 1/3 & \text{si } s' = s + \Delta \mathbf{x}_{\perp 1} \quad (\text{Desvío ortogonal izquierdo}) \\ > 1/3 & \text{si } s' = s + \Delta \mathbf{x}_{\perp 2} \quad (\text{Desvío ortogonal derecho})  > \end{cases}$$
> 
> 
> Esto implica que un robot que intente avanzar a la derecha ($a = 2$) tiene un $66.7\%$ de probabilidad de patinar hacia arriba o hacia abajo. Una política en lazo abierto o una heurística sin memoria colapsa inevitablemente en caídas repetidas dentro de los agujeros.

```python
# ============================================================================
# EXPERIMENTO 06: EVALUACIÓN DE TRACCIÓN Y ESTOCASTICIDAD EN FROZENLAKE-V1
# ============================================================================
import gymnasium as gym
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import random

# Fijar semillas estocásticas para reproducibilidad
random.seed(42)
np.random.seed(42)

# ----------------------------------------------------------------------------
# 1. PARÁMETRO EXPERIMENTAL (MODIFICAR AQUÍ EN CADA CORRIDA)
# ----------------------------------------------------------------------------
# Probar sucesivamente para llenar las dos filas de la TABLA 06:
#   Corrida 1: es_resbaladizo = False -> Suelo seco / Tracción perfecta
#   Corrida 2: es_resbaladizo = True  -> Superficie de hielo / Desvío estocástico
es_resbaladizo = False  # <-- MODIFICA A: True PARA LA SEGUNDA CORRIDA

corridas_totales = 100
max_pasos_episodio = 100

# ----------------------------------------------------------------------------
# 2. MOTOR DE EVALUACIÓN MONTE CARLO EN FROZENLAKE
# ----------------------------------------------------------------------------
env_lake = gym.make('FrozenLake-v1', is_slippery=es_resbaladizo)

desenlaces = []
historial_pasos = []

for _ in range(corridas_totales):
    s, _ = env_lake.reset()
    pasos = 0
    while True:
        pasos += 1
        # Heurística de avance natural hacia la esquina inferior derecha:
        # Alterna entre comando 1: Abajo (Down) y comando 2: Derecha (Right)
        a = random.choice([1, 2])
        
        s_next, r, term, trunc, _ = env_lake.step(a)
        
        if term:
            if r > 0.0:
                desenlaces.append("Meta (Éxito)")
            else:
                desenlaces.append("Hoyo (Caída)")
            historial_pasos.append(pasos)
            break
            
        if trunc:
            desenlaces.append("Timeout")
            historial_pasos.append(pasos)
            break

# ----------------------------------------------------------------------------
# 3. CÁLCULO DE MÉTRICAS EXPERIMENTALES
# ----------------------------------------------------------------------------
exitos = desenlaces.count("Meta (Éxito)")
caidas = desenlaces.count("Hoyo (Caída)")
timeouts = desenlaces.count("Timeout")

pct_exito = (exitos / corridas_totales) * 100.0
pct_caida = (caidas / corridas_totales) * 100.0
pasos_promedio = np.mean(historial_pasos)

# ----------------------------------------------------------------------------
# 4. REPORTE EN CONSOLA (COPIAR DIRECTO A LA TABLA 06)
# ----------------------------------------------------------------------------
superficie_str = "HIELO PURO (is_slippery=True)" if es_resbaladizo else "SUELO SECO (is_slippery=False)"

print("=" * 76)
print(f" EVALUACIÓN DE SUPERFICIE: {superficie_str}")
print("=" * 76)
print(f" -> Episodios Evaluados:          {corridas_totales}")
print(f" -> Porcentaje de Éxitos a Meta:  {pct_exito:05.1f}% ({exitos}/{corridas_totales})")
print(f" -> Porcentaje de Caídas al Hoyo: {pct_caida:05.1f}% ({caidas}/{corridas_totales})")
print(f" -> Pasos Medios de Supervivencia:{pasos_promedio:05.1f} pasos")
print("=" * 76)

# ----------------------------------------------------------------------------
# 5. VISUALIZACIÓN DUAL: FRECUENCIAS Y DISTRIBUCIÓN DE SUPERVIVENCIA
# ----------------------------------------------------------------------------
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(11, 4), dpi=110)

# Gráfico 1: Tasa de Desenlaces
orden_desenlaces = ["Meta (Éxito)", "Hoyo (Caída)"]
conteos = [exitos, caidas]
colores = ['#16a34a', '#dc2626']

barras = ax1.bar(orden_desenlaces, conteos, color=colores, width=0.45, edgecolor='black', alpha=0.85)
ax1.set_title(f'Desenlaces | {superficie_str}', fontweight='bold', fontsize=9.5)
ax1.set_ylabel('Frecuencia Absoluta (de 100 ep)')
ax1.set_ylim(0, 105)
ax1.grid(True, linestyle='--', alpha=0.3, axis='y')

for b in barras:
    h = b.get_height()
    ax1.text(b.get_x() + b.get_width()/2.0, h + 2, f"{h} ({h:.0f}%)", ha='center', va='bottom', fontweight='bold', fontsize=9)

# Gráfico 2: Histograma de Pasos de Supervivencia
ax2.hist(historial_pasos, bins=range(1, max(historial_pasos) + 3), color='#0284c7', edgecolor='black', alpha=0.75)
ax2.axvline(pasos_promedio, color='red', linestyle='--', linewidth=1.5, label=f'Media: {pasos_promedio:.1f} pasos')
ax2.set_title('Histograma de Pasos por Episodio', fontweight='bold', fontsize=9.5)
ax2.set_xlabel('Número de Pasos hasta Concluir')
ax2.set_ylabel('Frecuencia')
ax2.legend(frameon=True)
ax2.grid(True, linestyle='--', alpha=0.3)

plt.tight_layout()
plt.show()
```

## Experimento 07: Expectación de Bellman: Pizarrón vs. Python

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> 
> 
> A diferencia de los métodos de control en lazo abierto, la **Ecuación de Expectación de Bellman** evalúa cuantitativamente todas las contingencias estocásticas que el actuador puede experimentar antes de ejecutar físicamente un movimiento.
> Para un estado de aproximación final $s = (1, 4)$ (ubicado exactamente a un paso de la boca de la gaveta), el controlador mecatrónico debe sopesar dos alternativas operativas:
> 1. **Acción Activa ($a = \text{AVANZAR}$):** Sujeta a resbalón estocástico con probabilidad $p_{\text{resbalon}} \in [0, 1]$:
> * Con probabilidad $(1 - p_{\text{resbalon}})$ el mecanismo tracciona con éxito: el robot se acopla a la gaveta recibiendo $R_{\text{éxito}} = +100.0\text{ pts}$ y alcanza el estado terminal cuyo valor futuro es nulo ($V(S_{\text{meta}}) = 0.0$).
> * Con probabilidad $p_{\text{resbalon}}$ las patas patinan: el robot no avanza, sufre una penalización física por fricción o sobretorque mecánico $R_{\text{fallo}}$ y permanece en el estado actual cuyo valor consolidado es $V(S_{\text{actual}}) = 25.0\text{ pts}$.
> 
> 
> 
> 
> $$Q(s, \text{AVANZAR}) = (1 - p_{\text{resbalon}}) \left[ R_{\text{éxito}} + \gamma V(S_{\text{meta}}) \right] + p_{\text{resbalon}} \left[ R_{\text{fallo}} + \gamma V(S_{\text{actual}}) \right]$$
> 
> 
> 2. **Acción Pasiva ($a = \text{DETENERSE}$):** Es 100% determinista. El robot decide no arriesgar la caja de engranajes, permanece inmóvil pagando el consumo basal de batería $R_{\text{espera}} = -1.0\text{ pt}$ y preserva el valor del estado con factor de descuento $\gamma = 0.95$:
> 
> 
> $$Q(s, \text{DETENERSE}) = R_{\text{espera}} + \gamma V(S_{\text{actual}}) = -1.0 + 0.95(25.0) = \mathbf{22.75\text{ puntos}}$$
> 
> 
> El criterio de decisión viene regido por la **Política de Bellman**:
> $$\pi^*(s) = \arg\max_{a} Q(s, a)$$
> 
> 
> Si el margen de seguridad $\Delta Q = Q(s, \text{AVANZAR}) - Q(s, \text{DETENERSE}) > 0$, el robot asume el riesgo motriz de avanzar; si $\Delta Q \le 0$, el costo del patinaje supera el incentivo del acople y el controlador opta por abortar la aproximación.

```python
# ============================================================================
# EXPERIMENTO 07: EVALUADOR NUMÉRICO DE EXPECTACIÓN DE BELLMAN
# ============================================================================
import numpy as np
import matplotlib.pyplot as plt

# ----------------------------------------------------------------------------
# 1. PARÁMETROS EXPERIMENTALES (MODIFICAR AQUÍ EN CADA CORRIDA)
# ----------------------------------------------------------------------------
# Modifica estas dos variables para registrar cada fila de la TABLA 07:
#   Corrida 1 (Estándar):        r_fallo = -1.0,   p_resbalon = 0.20
#   Corrida 2 (Falla Térmica):   r_fallo = -20.0,  p_resbalon = 0.20
#   Corrida 3 (Engranes Dañados):r_fallo = -35.0,  p_resbalon = 0.50
r_fallo = -1.0         # <-- MODIFICA ESTA PENALIZACIÓN EN CADA CORRIDA
p_resbalon = 0.20      # <-- MODIFICA ESTA PROBABILIDAD DE RESBALÓN

# Parámetros fijos del Proceso de Decisión de Markov
r_exito = 100.0        # Recompensa por acople exitoso a gaveta (+100 pts)
v_meta = 0.0           # Estado terminal (valor futuro nulo)
v_actual = 25.0        # Valor de persistir en la casilla actual
gamma = 0.95           # Factor de descuento temporal
r_espera = -1.0        # Costo de batería por detenerse

# ----------------------------------------------------------------------------
# 2. DEDUCCIÓN COMPUTACIONAL DE LA EXPECTACIÓN DE BELLMAN
# ----------------------------------------------------------------------------
# Rama 1: Tracción exitosa nominal hacia la meta
aporte_exito = (1.0 - p_resbalon) * (r_exito + gamma * v_meta)

# Rama 2: Patinaje con penalización mecánica
aporte_fallo = p_resbalon * (r_fallo + gamma * v_actual)

# Valor Q total para la acción AVANZAR
q_avanzar = aporte_exito + aporte_fallo
```

## Experimento 08: Q-Learning en Vivo: Comparativa Visual Antes vs. Después

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> El algoritmo de Q-Learning prescinde del modelo de transición $\mathcal{P}(s' \mid s, a)$. El robot aprende la matriz óptima $Q^*(s, a)$ a través de la interacción directa mediante la actualización de Diferencia Temporal (TD):
>
> $$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \left[ r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t) \right]$$
>
> Donde la discrepancia entre el corchete y la predicción actual se denomina **Error TD** ($\delta_t$).

```python
# ============================================================================
# EXPERIMENTO 08: ENTRENAMIENTO COMPLETO DE TABLA Q Y COMPARATIVA EN VIVO
# ============================================================================
env_q = gym.make('CliffWalking-v0')
Q_matriz = np.zeros((env_q.observation_space.n, env_q.action_space.n))

alpha = 0.10
gamma = 0.95
epsilon = 0.20
episodios_totales = 350

# Bucle de aprendizaje TD
for ep in range(episodios_totales):
    s, _ = env_q.reset()
    while True:
        if random.random() < epsilon:
            a = env_q.action_space.sample()
        else:
            a = np.argmax(Q_matriz[s, :])
        s_next, rew, term, trunc, _ = env_q.step(a)
        
        # Regla de Bellman TD
        td_target = rew + gamma * np.max(Q_matriz[s_next, :])
        Q_matriz[s, a] += alpha * (td_target - Q_matriz[s, a])
        s = s_next
        if term or trunc: break

# Evaluacion limpia de la politica aprendida (Explotacion pura)
s, _ = env_q.reset(seed=42)
ruta_aprendida = [s]
while True:
    a_opt = np.argmax(Q_matriz[s, :])
    s, rew, term, _, _ = env_q.step(a_opt)
    ruta_aprendida.append(s)
    if term: break

print(f"Pasos del robot entrenado para cruzar el acantilado: {len(ruta_aprendida)-1}")
print(f"Trayectoria óptima aprendida: {ruta_aprendida}")
```

> ### Protocolo de Laboratorio: Modificación, Ejecución y Observación

> **¿Qué observarán?** Con $10$ episodios, la tabla $Q$ está vacía y el robot cae en el paso 1. Con $50$ episodios, descubre que subir a la fila 2 es seguro pero duda al final. Con $400$ episodios, la trayectoria converge a exactamente 13 pasos limpios bordeando la cornisa superior.

## Experimento 09: Dilema Exploración-Explotación ($\epsilon$-Greedy Decay)

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> Si $\epsilon$ es fijo y alto ($0.30$), el agente sigue saltando al abismo por pura curiosidad incluso después de haber aprendido la ruta óptima. Se introduce el decaimiento exponencial de exploración:
>
> $$\epsilon_{t+1} = \max(\epsilon_{\min}, \; \epsilon_t \cdot \lambda_{\text{decay}})$$
>
> Donde $\lambda_{\text{decay}} \in (0, 1)$ transiciona suavemente al robot de explorador novato a ejecutor industrial preciso.

```python
# ============================================================================
# EXPERIMENTO 09: DECAIMIENTO DE EXPLORACIÓN (EPSILON DECAY)
# ============================================================================
def entrenar_con_decay(epsilon_decay=0.99, eps_min=0.01, total_ep=300):
    env = gym.make('CliffWalking-v0')
    Q = np.zeros((env.observation_space.n, env.action_space.n))
    eps = 1.0
    historial_retornos = []
    
    for ep in range(total_ep):
        s, _ = env.reset()
        g_ep = 0
        while True:
            a = env.action_space.sample() if random.random() < eps else np.argmax(Q[s, :])
            s_next, r, term, trunc, _ = env.step(a)
            Q[s, a] += 0.10 * (r + 0.95 * np.max(Q[s_next, :]) - Q[s, a])
            s = s_next
            g_ep += r
            if term or trunc: break
        eps = max(eps_min, eps * epsilon_decay)
        historial_retornos.append(g_ep)
    return historial_retornos

curva_fija = entrenar_con_decay(epsilon_decay=1.0)       # Epsilon constante = 1.0
curva_decay = entrenar_con_decay(epsilon_decay=0.985)    # Decaimiento balanceado

plt.figure(figsize=(7, 3))
plt.plot(curva_fija, label='Epsilon Fijo (Ruido Continuo)', alpha=0.4, color='red')
plt.plot(curva_decay, label='Epsilon Decay (Convergencia Limpia)', color='green')
plt.title('Experimento 09: Impacto de Epsilon Decay en la Estabilidad de Control', fontweight='bold')
plt.xlabel('Episodio')
plt.ylabel('Retorno del Episodio')
plt.ylim(-150, 0)
plt.legend()
plt.tight_layout()
plt.show()
```

> [!TIP]
> ### Protocolo de Laboratorio: Modificación, Ejecución y Observación
> **¿Qué deben modificar?** Ajusten `epsilon_decay` a $0.90$ (decaimiento ultrarrápido) y luego a $0.999$ (decaimiento ultralento). Observen la curva de retorno en Colab.  
> **¿Qué observarán?** Con $0.90$, el agente deja de explorar en el episodio 20 antes de encontrar la meta y se estanca en una política subóptima permanente. Con $0.985$, la curva sube suavemente hasta estabilizarse en $-13.0$ puntos constantes.

### TABLA 09: Dinámica de Convergencia según la Tasa de Decaimiento

| Decaimiento ($\lambda_{\text{decay}}$) | Episodio de Convergencia | Retorno Final Estable | Varianza Residual | Comportamiento Operativo del Robot |
| :--- | :---: | :---: | :---: | :--- |
| $\lambda = 1.00$ (Sin Decaimiento) | Nunca converge | $-45.0\text{ pts}$ | Muy Alta | El robot salta al vacío intermitentemente por azar. |
| $\lambda = 0.985$ (Balanceado) | $\approx \text{Episodio } 140$ | $-13.0\text{ pts}$ | Nula ($\sigma = 0$) | Explora al inicio y ejecuta la trayectoria óptima al final. |
| $\lambda = 0.90$ (Prematuro) | $\approx \text{Episodio } 25$ | $-90.0\text{ pts}$ | Nula | Se congela en una política fallida por falta de exploración. |

## Experimento 10: Estrés Paramétrico Conjunto ($\alpha$ vs. $\gamma$) y Mapa de Calor

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> El factor de descuento $\gamma \in [0, 1)$ define el horizonte temporal efectivo de planeación: $H_{\text{efectivo}} \approx \frac{1}{1 - \gamma}$. Si la meta está a $D$ pasos de distancia y $\gamma \to 0$, el gradiente decae como $\gamma^D \to 0$, provocando que el robot se vuelva miope. Paralelamente, si la tasa de aprendizaje es excesiva ($\alpha \ge 1.0$), el algoritmo oscila y diverge numéricamente.

```python
# ============================================================================
# EXPERIMENTO 10: HEATMAP DE LA TABLA Q APRENDIDA Y ESTRÉS DE GAMMA/ALPHA
# ============================================================================
def entrenar_experimento_estres(alpha_val, gamma_val):
    env = gym.make('CliffWalking-v0')
    Q = np.zeros((env.observation_space.n, env.action_space.n))
    for ep in range(350):
        s, _ = env.reset()
        while True:
            a = env.action_space.sample() if random.random() < 0.15 else np.argmax(Q[s, :])
            s_next, r, term, trunc, _ = env.step(a)
            Q[s, a] += alpha_val * (r + gamma_val * np.max(Q[s_next, :]) - Q[s, a])
            s = s_next
            if term or trunc: break
    return Q

# Matriz con hiperparámetros óptimos
Q_optimo = entrenar_experimento_estres(alpha_val=0.10, gamma_val=0.95)
V_mapa = np.max(Q_optimo, axis=1).reshape((4, 12))

plt.figure(figsize=(9, 3), dpi=120)
sns.heatmap(V_mapa, annot=True, fmt=".1f", cmap="viridis", linewidths=0.5,
            cbar_kws={'label': 'Valor Óptimo V*(s)'})
plt.title('Experimento 10: Mapa de Calor de la Función de Valor V*(s) Aprendida', fontweight='bold')
plt.xlabel('Columnas (0=Inicio a 11=Meta)')
plt.ylabel('Filas (Fila 3=Acantilado)')
plt.tight_layout()
plt.show()
```
