## Experimento 05: API Estándar Gymnasium e Inspección de `CliffWalking-v1`

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> 
> 
> En el desarrollo de sistemas ciberfísicos, los algoritmos de control por refuerzo se desacoplan del hardware mediante la interfaz estándar de **Gymnasium**. Toda invocación al método motor `env.step(action)` devuelve de manera estricta la tupla de cinco variables:
> $$(s_{t+1}, \; r_{t+1}, \; \text{terminated}, \; \text{truncated}, \; \text{info})$$
> 
> 
> 1. $s_{t+1} \in \mathcal{S}$: Nuevo estado escalar indexado en formato *Row-Major*. En la cuadrícula de $4 \times 12 = 48\text{ casillas}$ de `CliffWalking-v1`, los estados se distribuyen del $0$ al $47$.
> 2. $r_{t+1} \in \mathbb{R}$: Señal de recompensa inmediata. Cada paso en terreno regular descuenta $-1.0\text{ pt}$ (costo energético de batería), mientras que precipitarse al vacío descuenta $-100.0\text{ pts}$.
> 
> 
> 3. $\text{terminated} \in \{\text{True}, \text{False}\}$: Bandera booleana de fin natural del MDP (acople exitoso en la meta $s = 47$).
> 
> 
> 4. $\text{truncated} \in \{\text{True}, \text{False}\}$: Bandera de corte artificial o parada de emergencia cuando se excede el límite temporal máximo ($T \ge T_{\max}$) sin alcanzar una condición terminal física.
> 
> 
> 5. $\text{info}$: Diccionario auxiliar con telemetría interna y probabilidades de transición del simulador.
> 
> 
> 
> 
> Las acciones del actuador corresponden a cuatro direcciones discretas:
> $$\mathcal{A} = \{0: \text{Arriba (Up)}, \; 1: \text{Derecha (Right)}, \; 2: \text{Abajo (Down)}, \; 3: \text{Izquierda (Left)}\}$$
> 
>

## Experimento 06: Superficies de Hielo y Estocasticidad en `FrozenLake-v1`

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> El parámetro `is_slippery` de `FrozenLake-v1` implementa un modelo de transición donde el comando del actuador tiene únicamente $\frac{1}{3}$ de probabilidad de ejecutarse en la dirección solicitada y $\frac{2}{3}$ de desviarse ortogonalmente:
>
> $$\mathcal{P}(s_{\text{deseado}} \mid s, a) = \frac{1}{3}, \qquad \mathcal{P}(s_{\perp 1} \mid s, a) = \frac{1}{3}, \qquad \mathcal{P}(s_{\perp 2} \mid s, a) = \frac{1}{3}$$

```python
# ============================================================================
# EXPERIMENTO 06: EVALUACIÓN DETERMINISTA VS ESTOCÁSTICA EN GYMNASIUM
# ============================================================================
def evaluar_lago(slippery_flag, corridas=100):
    env_lake = gym.make('FrozenLake-v1', is_slippery=slippery_flag)
    victorias, caidas = 0, 0
    pasos_acum = []
    
    for _ in range(corridas):
        s, _ = env_lake.reset()
        pasos = 0
        while True:
            pasos += 1
            # Heurística simple: Intentar avanzar a la meta (Abajo=1, Derecha=2)
            a = random.choice([1, 2])
            s, r, term, trunc, _ = env_lake.step(a)
            if term:
                if r > 0: victorias += 1
                else:     caidas += 1
                pasos_acum.append(pasos)
                break
            if trunc: break
    return victorias, caidas, np.mean(pasos_acum)

v_sec, c_sec, p_sec = evaluar_lago(slippery_flag=False)
v_hie, c_hie, p_hie = evaluar_lago(slippery_flag=True)

print(f"SUELO SECO (is_slippery=False):  Éxito: {v_sec:02d}% | Caídas: {c_sec:02d}% | Pasos: {p_sec:.1f}")
print(f"HIELO PURO (is_slippery=True):   Éxito: {v_hie:02d}% | Caídas: {c_hie:02d}% | Pasos: {p_hie:.1f}")
```

## Experimento 07: Expectación de Bellman: Pizarrón vs. Python

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> La Ecuación de Expectación de Bellman para el valor de acción $Q(s, a)$ promedia ponderadamente todas las contingencias futuras:
>
> $$Q(s, a) = \sum_{s'} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V(s') \right]$$
>
> Si el robot está en $s = (1, 4)$ y la acción `AVANZAR` tiene $80\%$ de probabilidad de acople ($V = 0, R = +100$) y $20\%$ de patinaje ($V = 25.0, R = -1.0$) con $\gamma = 0.95$:
>
> $$Q(s, \text{AV}) = 0.80[100.0 + 0] + 0.20[-1.0 + 0.95(25.0)] = 80.0 + 0.20(22.75) = \mathbf{84.55\text{ puntos}}$$

```python
# ============================================================================
# EXPERIMENTO 07: EVALUADOR NUMÉRICO DE EXPECTACIÓN DE BELLMAN
# ============================================================================
def calcular_bellman_analitico(r_exito, r_fallo, v_actual, v_meta, p_resbalon, gamma=0.95):
    # Rama de éxito de tracción
    aporte_exito = (1.0 - p_resbalon) * (r_exito + gamma * v_meta)
    # Rama de patinaje estocástico
    aporte_fallo = p_resbalon * (r_fallo + gamma * v_actual)
    return aporte_exito + aporte_fallo

q_calculado = calcular_bellman_analitico(100.0, -1.0, 25.0, 0.0, p_resbalon=0.20, gamma=0.95)
q_detenerse = -1.0 + 0.95 * 25.0

print(f"Q(s, AVANZAR) calculado:   {q_calculado:.2f} pts (Teórico pizarra: 84.55 pts)")
print(f"Q(s, DETENERSE) calculado: {q_detenerse:.2f} pts (Teórico pizarra: 22.75 pts)")
```

> [!TIP]
> ### Protocolo de Laboratorio: Modificación, Ejecución y Observación
> **¿Qué deben modificar?** En la función, cambien la penalización por resbalón `r_fallo` de $-1.0$ a $-35.0$ (daño en caja de engranajes por sobretorque). Despejen en su libreta el nuevo valor de $Q$ y verifiquen si Python entrega exactamente el mismo número.  
> **¿Qué observarán?** Con $R_{\text{fallo}} = -35.0$, el valor de avanzar cae de $84.55$ a $77.75$ puntos, demostrando que castigar el patinaje reduce el margen de ventaja sobre la acción pasiva de detenerse ($22.75$ pts).

## Experimento 08: Q-Learning en Vivo: Comparativa Visual Antes vs. Después

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> El algoritmo de Q-Learning prescinde del modelo de transición $\mathcal{P}(s' \mid s, a)$. El robot aprende la matriz óptima $Q^*(s, a)$ a través de la interacción directa mediante la actualización de Diferencia Temporal (TD):
>
> $$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \left[ r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t) \right]$$
>
> Donde la discrepancia entre el corchete y la predicción actual se denomina **Error TD** ($\delta_t$).

```python
# ============================================================================
# EXPERIMENTO 08: ENTRENAMIENTO COMPLETO DE TABLA Q Y COMPARATIVA EN VIVO
# ============================================================================
env_q = gym.make('CliffWalking-v0')
Q_matriz = np.zeros((env_q.observation_space.n, env_q.action_space.n))

alpha = 0.10
gamma = 0.95
epsilon = 0.20
episodios_totales = 350

# Bucle de aprendizaje TD
for ep in range(episodios_totales):
    s, _ = env_q.reset()
    while True:
        if random.random() < epsilon:
            a = env_q.action_space.sample()
        else:
            a = np.argmax(Q_matriz[s, :])
        s_next, rew, term, trunc, _ = env_q.step(a)
        
        # Regla de Bellman TD
        td_target = rew + gamma * np.max(Q_matriz[s_next, :])
        Q_matriz[s, a] += alpha * (td_target - Q_matriz[s, a])
        s = s_next
        if term or trunc: break

# Evaluacion limpia de la politica aprendida (Explotacion pura)
s, _ = env_q.reset(seed=42)
ruta_aprendida = [s]
while True:
    a_opt = np.argmax(Q_matriz[s, :])
    s, rew, term, _, _ = env_q.step(a_opt)
    ruta_aprendida.append(s)
    if term: break

print(f"Pasos del robot entrenado para cruzar el acantilado: {len(ruta_aprendida)-1}")
print(f"Trayectoria óptima aprendida: {ruta_aprendida}")
```

> [!TIP]
> ### Protocolo de Laboratorio: Modificación, Ejecución y Observación
> **¿Qué deben modificar?** En la línea 10, cambien `episodios_totales` a solo **$10$** episodios (aprendizaje incipiente), luego a **$50$** y finalmente a **$400$**. Evalúen la longitud de la ruta y si el robot sobrevive.  
> **¿Qué observarán?** Con $10$ episodios, la tabla $Q$ está vacía y el robot cae en el paso 1. Con $50$ episodios, descubre que subir a la fila 2 es seguro pero duda al final. Con $400$ episodios, la trayectoria converge a exactamente 13 pasos limpios bordeando la cornisa superior.

## Experimento 09: Dilema Exploración-Explotación ($\epsilon$-Greedy Decay)

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> Si $\epsilon$ es fijo y alto ($0.30$), el agente sigue saltando al abismo por pura curiosidad incluso después de haber aprendido la ruta óptima. Se introduce el decaimiento exponencial de exploración:
>
> $$\epsilon_{t+1} = \max(\epsilon_{\min}, \; \epsilon_t \cdot \lambda_{\text{decay}})$$
>
> Donde $\lambda_{\text{decay}} \in (0, 1)$ transiciona suavemente al robot de explorador novato a ejecutor industrial preciso.

```python
# ============================================================================
# EXPERIMENTO 09: DECAIMIENTO DE EXPLORACIÓN (EPSILON DECAY)
# ============================================================================
def entrenar_con_decay(epsilon_decay=0.99, eps_min=0.01, total_ep=300):
    env = gym.make('CliffWalking-v0')
    Q = np.zeros((env.observation_space.n, env.action_space.n))
    eps = 1.0
    historial_retornos = []
    
    for ep in range(total_ep):
        s, _ = env.reset()
        g_ep = 0
        while True:
            a = env.action_space.sample() if random.random() < eps else np.argmax(Q[s, :])
            s_next, r, term, trunc, _ = env.step(a)
            Q[s, a] += 0.10 * (r + 0.95 * np.max(Q[s_next, :]) - Q[s, a])
            s = s_next
            g_ep += r
            if term or trunc: break
        eps = max(eps_min, eps * epsilon_decay)
        historial_retornos.append(g_ep)
    return historial_retornos

curva_fija = entrenar_con_decay(epsilon_decay=1.0)       # Epsilon constante = 1.0
curva_decay = entrenar_con_decay(epsilon_decay=0.985)    # Decaimiento balanceado

plt.figure(figsize=(7, 3))
plt.plot(curva_fija, label='Epsilon Fijo (Ruido Continuo)', alpha=0.4, color='red')
plt.plot(curva_decay, label='Epsilon Decay (Convergencia Limpia)', color='green')
plt.title('Experimento 09: Impacto de Epsilon Decay en la Estabilidad de Control', fontweight='bold')
plt.xlabel('Episodio')
plt.ylabel('Retorno del Episodio')
plt.ylim(-150, 0)
plt.legend()
plt.tight_layout()
plt.show()
```

> [!TIP]
> ### Protocolo de Laboratorio: Modificación, Ejecución y Observación
> **¿Qué deben modificar?** Ajusten `epsilon_decay` a $0.90$ (decaimiento ultrarrápido) y luego a $0.999$ (decaimiento ultralento). Observen la curva de retorno en Colab.  
> **¿Qué observarán?** Con $0.90$, el agente deja de explorar en el episodio 20 antes de encontrar la meta y se estanca en una política subóptima permanente. Con $0.985$, la curva sube suavemente hasta estabilizarse en $-13.0$ puntos constantes.

### TABLA 09: Dinámica de Convergencia según la Tasa de Decaimiento

| Decaimiento ($\lambda_{\text{decay}}$) | Episodio de Convergencia | Retorno Final Estable | Varianza Residual | Comportamiento Operativo del Robot |
| :--- | :---: | :---: | :---: | :--- |

## Experimento 10: Estrés Paramétrico Conjunto ($\alpha$ vs. $\gamma$) y Mapa de Calor

> [!NOTE]
> ### Fundamento Matemático y Conexión Teórica
> El factor de descuento $\gamma \in [0, 1)$ define el horizonte temporal efectivo de planeación: $H_{\text{efectivo}} \approx \frac{1}{1 - \gamma}$. Si la meta está a $D$ pasos de distancia y $\gamma \to 0$, el gradiente decae como $\gamma^D \to 0$, provocando que el robot se vuelva miope. Paralelamente, si la tasa de aprendizaje es excesiva ($\alpha \ge 1.0$), el algoritmo oscila y diverge numéricamente.

```python
# ============================================================================
# EXPERIMENTO 10: HEATMAP DE LA TABLA Q APRENDIDA Y ESTRÉS DE GAMMA/ALPHA
# ============================================================================
def entrenar_experimento_estres(alpha_val, gamma_val):
    env = gym.make('CliffWalking-v0')
    Q = np.zeros((env.observation_space.n, env.action_space.n))
    for ep in range(350):
        s, _ = env.reset()
        while True:
            a = env.action_space.sample() if random.random() < 0.15 else np.argmax(Q[s, :])
            s_next, r, term, trunc, _ = env.step(a)
            Q[s, a] += alpha_val * (r + gamma_val * np.max(Q[s_next, :]) - Q[s, a])
            s = s_next
            if term or trunc: break
    return Q

# Matriz con hiperparámetros óptimos
Q_optimo = entrenar_experimento_estres(alpha_val=0.10, gamma_val=0.95)
V_mapa = np.max(Q_optimo, axis=1).reshape((4, 12))

plt.figure(figsize=(9, 3), dpi=120)
sns.heatmap(V_mapa, annot=True, fmt=".1f", cmap="viridis", linewidths=0.5,
            cbar_kws={'label': 'Valor Óptimo V*(s)'})
plt.title('Experimento 10: Mapa de Calor de la Función de Valor V*(s) Aprendida', fontweight='bold')
plt.xlabel('Columnas (0=Inicio a 11=Meta)')
plt.ylabel('Filas (Fila 3=Acantilado)')
plt.tight_layout()
plt.show()
```

> [!TIP]
> ### Protocolo de Laboratorio: Modificación, Ejecución y Observación
> **¿Qué deben modificar?** En la función, ejecuten las tres combinaciones de la TABLA 10: **Caso A** ($\alpha=0.10, \gamma=0.95$), **Caso B** ($\alpha=0.10, \gamma=0.10$, miopía extrema) y **Caso C** ($\alpha=0.95, \gamma=0.95$, tasa de actualización agresiva).
